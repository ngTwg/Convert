# 📦 MultiConvert Release Notes

## 🇻🇳 Tiếng Việt (Vietnamese)

🚀 **Chào mừng đến với MultiConvert v0.1.0!**

MultiConvert là công cụ chuyển đổi tài liệu đa định dạng siêu mạnh mẽ dành cho Windows, hỗ trợ hàng chục định dạng (PDF, Word, Markdown, HTML, Hình ảnh,...).

### 📥 Hướng dẫn tải và cài đặt (Chỉ mất 1 phút)
1. Kéo xuống dưới phần **Assets**.
2. Bấm tải file có đuôi `.exe` (VD: `MultiConvert_Setup_v0.1.0.exe`).
3. Mở file vừa tải về. Bam **Next** liên tục để cài đặt.
4. (Tùy chọn) Trong lúc cài cài đặt, bạn có thể tích chọn tự động tải thêm **LibreOffice** (nếu hay chuyển Word sang PDF) hoặc **Tesseract OCR** (nếu hay quét chữ từ hình ảnh). Nếu máy đã có sẵn, phần mềm sẽ tự nhận diện!
5. Cài xong, ra màn hình chính (Desktop) nhấn đúp vào biểu tượng **MultiConvert** để sử dụng ngay!

## 🇬🇧 English

🚀 **Welcome to MultiConvert v0.1.0!**

MultiConvert is a powerful, multi-format document converter for Windows, supporting dozens of file formats (PDF, Word, Markdown, HTML, Images...).

### 📥 How to download and install (Takes 1 minute)
1. Scroll down to the **Assets** section below.
2. Download the `.exe` setup file (e.g., `MultiConvert_Setup_v0.1.0.exe`).
3. Run the downloaded file. Click **Next** to install.
4. (Optional) During installation, you can check the boxes to automatically download **LibreOffice** (great for Word to PDF conversions) or **Tesseract OCR** (for extracting text from images). If you already have them installed, the app will detect them automatically!
5. Once finished, double-click the **MultiConvert** icon on your Desktop to start converting!
