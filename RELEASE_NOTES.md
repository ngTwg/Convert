## v0.2.0 (Latest)

**Massive Format Expansion!**
- **35+ input formats** (up from 19)
- **25+ output formats** (up from 9)

**New Markup/Wiki Formats:**
- LaTeX/TEX
- Org-mode
- AsciiDoc
- MediaWiki
- Textile
- OPML (outlines)
- FictionBook (FB2)
- Jira/Confluence

**New Code/Data Formats:**
- Jupyter Notebooks (IPYNB)
- JSON
- Man pages
- T2T (txt2tags)
- TWiki, TikiWiki

**New Presentation Outputs:**
- PowerPoint (PPTX)
- Reveal.js, DZSlides, Slideous, Slidy, S5

**New Image Formats (OCR):**
- ICO (icons)
- HEIC/HEIF (iOS photos)

**Installer Improvements:**
- Updated LibreOffice download to v24.2.5
- Better detection of installed tools
- English language support for installer messages

## English

**Welcome to MultiConvert v0.2.0!**

MultiConvert is a powerful, multi-format document converter for Windows.

### What's New in v0.2.0
- **35+ input formats** (up from 19)
- **25+ output formats** (up from 9)
- New formats: LaTeX, Org-mode, AsciiDoc, MediaWiki, Jupyter Notebooks, JSON, PPTX, HEIC...

### How to download and install (Takes 1 minute)
1. Scroll down to the **Assets** section below.
2. Download the `.exe` setup file (e.g., `MultiConvert_Setup_v0.2.0.exe`).
3. Run the downloaded file. Click **Next** to install.
4. (Optional) During installation, you can check the boxes to automatically download **LibreOffice** or **Tesseract OCR**.
5. Once finished, double-click the **MultiConvert** icon on your Desktop to start converting!
